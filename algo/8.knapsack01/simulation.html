d[i][j] = max( d[i-1][j-w[i]] + v[i],  ← 아이템 i를 넣을 때 d[i-1][j]                      ← 아이템 i를 넣지 않을 때 )  단, j < w[i] 이면 넣을 수 없으므로 d[i-1][j] 그대로

왜 1차원으로 압축 가능할까?
2차원 점화식:
d[i][j] = max(d[i-1][j-w]+v, d[i-1][j])
i행은 오직 i-1행만 참조합니다.
→ 1차원 배열 하나로 덮어써도 OK!
⚠ j는 반드시 큰 값 → 작은 값 순서로!
왼→오 순서라면: dp[j-w]가 이미
이번 아이템으로 업데이트된 값
→ 같은 아이템을 두 번 선택하는 오류!
오→왼 순서라면: dp[j-w]는 아직
이번 아이템으로 업데이트되기 전 값
→ 이전 행(i-1행)의 값과 동일하게 유지 ✓
