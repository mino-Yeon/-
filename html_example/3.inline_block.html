📦 Block / Inline / Inline-block 요소

HTML 요소는 기본적으로 어떻게 공간을 차지하는지에 따라 block, inline, inline-block으로 구분됩니다.

Block 요소란?
블록 요소는 항상 새 줄에서 시작하고, 가로 너비를 부모의 100%만큼 자동으로 차지합니다. 쉽게 말해 "한 줄을 통째로 차지하는 박스"입니다.
✅ 새 줄에서 시작앞뒤 요소와 줄이 바뀝니다
✅ 가로 100% 자동 차지부모 요소의 너비를 가득 채웁니다
✅ width / height 지정 가능크기를 직접 설정할 수 있습니다
✅ margin / padding 전방향 적용상하좌우 모두 여백이 정상 동작합니다
대표적인 Block 태그
<div> <p> <h1> ~ <h6> <ul> <ol> <li> <header> <nav> <main> <section> <article> <aside> <footer> <form>
▶ 동작 시각화

위아래 요소 사이에 margin이 적용되어 간격이 생깁니다.

<div> — padding: 14px (내부 여백)
<div> — margin: 8px (외부 여백), padding: 14px (내부 여백)
🟠 주황 점선 = margin 영역 (요소 바깥 여백) — 상하좌우 모두 정상 적용
🔵 파란 실선 = 요소 자체 영역 (padding 포함) — 상하좌우 모두 정상 적용
/* block 요소: margin, padding 전방향 모두 적용 */ div { width: 300px; height: 60px; margin: 20px; /* ✅ 상하좌우 모두 적용 */ padding: 14px; /* ✅ 상하좌우 모두 적용 */ }
Inline 요소란?
인라인 요소는 새 줄로 바뀌지 않고 텍스트 흐름 안에서 나란히 배치됩니다. 콘텐츠 크기만큼만 자리를 차지하며, width/height와 상하 margin이 적용되지 않습니다.
✅ 새 줄 없이 나란히 배치텍스트처럼 옆으로 이어집니다
✅ 콘텐츠 크기만큼만 차지내용의 너비만큼만 공간을 가집니다
❌ width / height 지정 불가크기를 설정해도 적용되지 않습니다
❌ 상하 margin 적용 안 됨좌우 margin은 되지만 상하는 레이아웃에 영향을 주지 않습니다
⚠ 상하 padding은 시각적으로만padding 값이 보이긴 하지만 주변 레이아웃(위아래 요소 간격)을 밀지 않습니다
대표적인 Inline 태그
<span> <a> <strong> <em> <b> <i> <u> <label> <code> <br>
▶ 동작 시각화
문장 안에서 <span> 인라인 요소는 <span> 이렇게 텍스트와 함께 <span> 나란히 흐릅니다.
▶ 상하 margin — 적용 안 됨

이것이 "시각적으로만 적용"되는 의미입니다.
/* inline 요소의 margin/padding */ span { width: 200px; /* ❌ 무시됨 */ height: 50px; /* ❌ 무시됨 */ margin-left: 10px; /* ✅ 좌우 margin 적용 */ margin-right: 10px; /* ✅ 좌우 margin 적용 */ margin-top: 30px; /* ❌ 상하 margin 무시 */ margin-bottom: 30px; /* ❌ 상하 margin 무시 */ padding-left: 10px; /* ✅ 좌우 padding 적용 */ padding-top: 20px; /* ⚠ 시각적으로만 — 레이아웃 안 밀림 */ }
Inline-block 요소란?
인라인처럼 나란히 배치되면서, 블록처럼 width / height / 상하 margin·padding을 모두 지정할 수 있는 요소입니다. "나란히 놓을 수 있는 박스"라고 생각하면 됩니다.
✅ 나란히 배치인라인처럼 옆으로 이어집니다
✅ width / height 지정 가능블록처럼 크기를 직접 설정할 수 있습니다
✅ 상하 margin / padding 모두 적용상하좌우 여백이 모두 정상 동작합니다
❌ 가로 100% 자동 차지 안 함콘텐츠 크기만큼만 자리를 차지합니다
대표적인 Inline-block 태그
<img> <input> <button> <select> <textarea>

inline-block 요소는 margin-top/bottom을 주면 위아래 요소와의 간격이 실제로 벌어집니다.

위쪽 블록 요소 <div>
margin-top: 16px
inline-block — padding: 14px
margin-bottom: 16px
아래쪽 블록 요소 <div>
👆 inline처럼 나란히 배치되지만, 상하 margin이 위아래 요소를 실제로 밀어냅니다.
inline과 달리 padding도 레이아웃에 완전히 반영됩니다.
/* inline-block: margin, padding 전방향 모두 정상 적용 */ span { display: inline-block; width: 120px; /* ✅ 적용됨 */ height: 60px; /* ✅ 적용됨 */ margin-top: 20px; /* ✅ 실제로 위 요소를 밀어냄 */ padding-top: 14px; /* ✅ 레이아웃에 완전히 반영 */ }

display 속성으로 언제든 바꿀 수 있습니다
HTML 태그의 기본 display 값은 CSS로 자유롭게 변경할 수 있습니다.
/* 기본이 inline인 span을 block으로 */ span { display: block; } /* 기본이 block인 div를 inline으로 */ div { display: inline; } /* 어떤 요소든 inline-block으로 */ span { display: inline-block; } a { display: inline-block; }
