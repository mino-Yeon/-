① 가로형 수평 nav

가장 기본적인 내비게이션 구조입니다. ul에 display: flex를 적용해 메뉴를 가로로 나열합니다.

구조 포인트
<nav> — 내비게이션 의미 부여
<ul> — 메뉴 목록 (순서 없는 리스트)
<li> — 각 메뉴 항목
<a> — 실제 링크. padding은 반드시 a에 줘야 클릭 영역이 넓어집니다
활성 메뉴 표시 — border-bottom으로 하단 인디케이터

<!-- HTML --> <nav> <ul> <li class="active"><a href="#">홈</a></li> <li><a href="#">소개</a></li> <li><a href="#">서비스</a></li> <li><a href="#">포트폴리오</a></li> <li><a href="#">문의</a></li> </ul> </nav> /* CSS 핵심 */ nav ul { display: flex; /* 가로 배치 */ list-style: none; } nav ul li a { display: block; /* 클릭 영역 확보 */ padding: 14px 20px; /* padding은 a에! */ } nav ul li.active a { border-bottom: 3px solid #3498db; /* 활성 메뉴 표시 */ }

② 세로형 사이드바 nav

관리자 페이지나 대시보드에서 자주 쓰이는 패턴입니다. flex-direction: column으로 메뉴를 세로로 나열하고, 활성 메뉴는 border-bottom 대신 border-left로 표시합니다.

구조 포인트
<nav> — 사이드바 전체를 감싸는 내비게이션 태그
<div class="logo"> — 로고·브랜드명 영역. nav 안 첫 번째 자식으로 배치
<ul> > <li> > <a> — 메뉴 목록. 가로형과 동일한 HTML 구조
flex-direction: column — nav와 ul 모두에 적용해 세로 배치
활성 메뉴 표시 — 가로형의 border-bottom → 사이드바는 border-left
페이지 레이아웃 — nav를 고정 너비, 콘텐츠를 flex: 1로 나란히 배치

📌 사이드바 nav의 핵심은 flex-direction: column

HTML 구조는 가로형 nav와 완전히 동일합니다.
차이는 CSS 단 한 줄 — flex-direction: column.

활성 메뉴 인디케이터도 방향에 맞게 바뀝니다.
가로형 → border-bottom / 세로형 → border-left

flex-direction: column border-left (active) 관리자 페이지 대시보드
<!-- HTML : nav 안에 로고 div + ul --> <nav> <div class="logo">🌐 MyApp</div> <!-- 브랜드명 영역 --> <ul> <li class="active"><a href="#">🏠 홈</a></li> <li><a href="#">👤 프로필</a></li> <li><a href="#">📊 대시보드</a></li> <li><a href="#">⚙️ 설정</a></li> </ul> </nav> /* CSS 핵심 — 가로형과 비교 */ nav { width: 200px; display: flex; flex-direction: column; /* ← 가로형과의 차이 */ } nav ul { display: flex; flex-direction: column; /* ← ul도 세로 */ list-style: none; } nav ul li a { display: block; padding: 12px 20px; border-left: 3px solid transparent; /* 인디케이터 준비 */ } nav ul li.active a { border-left-color: #6c5ce7; /* 가로형 border-bottom → border-left */ } /* 페이지 레이아웃: nav + 콘텐츠 나란히 */ .page { display: flex; } .content { flex: 1; /* nav 제외한 나머지 공간 차지 */ }
