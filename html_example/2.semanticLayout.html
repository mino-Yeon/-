시맨틱 태그란 무엇인가?

태그 이름 자체가 콘텐츠의 의미를 나타내는 HTML 요소입니다. <div>와 달리 구조와 의미를 동시에 전달합니다.

<section> (article 내부)
🔍 왜 중요한가?

SEO, 접근성, 유지보수 세 측면 모두에서 시맨틱 태그는 <div>보다 명확한 이점을 제공합니다.

section — "실전 패턴" 주제 구획.

둘 다 유효한 HTML입니다. 디자인·팀 컨벤션에 따라 선택하세요. 중요한 건 일관성입니다.

figure + figcaption — alt와 무엇이 다른가?

alt 속성은 이미지 로드 실패 시 대체 텍스트입니다. figcaption은 항상 화면에 표시되는 캡션·출처·크레딧입니다. 둘은 역할이 다르므로 함께 사용합니다.
