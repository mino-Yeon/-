용어 정리

태그 = 엘리먼트 = 요소 — 모두 같은 말입니다.

<a href="https://example.com">링크 텍스트</a>
용어 예시 설명
태그명 a <a> 에서 꺽쇠를 제외한 이름
속성 (attribute) href="https://example.com" 태그에 추가 정보를 부여하는 것. 속성명 + 속성값으로 구성됩니다.
속성명 href 속성의 이름
속성값 "https://example.com" 속성에 할당된 값. 큰따옴표로 감쌉니다.
01
기본 문서 구조

모든 HTML 파일은 아래 뼈대로 시작합니다. 반드시 외워두세요.

<!DOCTYPE html> <!-- HTML5 문서임을 선언 --> <html lang="ko"> <!-- 문서 언어 설정 --> <head> <!-- 브라우저에게 전달하는 문서 정보 --> <meta charset="UTF-8"> <title>페이지 제목</title> <!-- 탭에 표시되는 제목 --> </head> <body> <!-- 화면에 실제로 보이는 내용 --> </body> </html>
02
주요 공통 속성

거의 모든 태그에 사용할 수 있는 속성들입니다.

id="값"
요소의 고유 식별자. 페이지 안에서 중복 불가. Java의 변수명처럼 유일해야 합니다.
class="값"
여러 요소를 그룹화. 중복 사용 가능. 공통 스타일링을 적용할 때 사용합니다.
style="CSS속성: 값"
해당 요소에만 인라인 스타일 적용. 외부 CSS보다 우선 적용됩니다.
<!-- id: 페이지 안에서 하나만 --> <div id="header">...</div> <!-- class: 여러 요소에 동일하게 --> <p class="highlight">첫 번째</p> <p class="highlight">두 번째</p>
03
주석 / 특수문자
<!-- 내용 -->
주석. 브라우저에 표시되지 않습니다.
<br>
줄바꿈
&nbsp;
공백 (Non-Breaking Space)
&lt; / &gt;
< / > 기호 출력 (태그로 인식되지 않게)
04
<link> / <meta>

<link> — 외부 CSS 파일을 연결할 때 사용합니다. <head> 안에 작성합니다.

<meta> — 문서 정보(인코딩, 반응형 설정 등)를 브라우저에 전달합니다.

<!-- 외부 CSS 파일 연결 --> <link rel="stylesheet" href="index.css"> <!-- 문자 인코딩 설정 (한글 깨짐 방지) --> <meta charset="UTF-8"> <!-- 모바일 반응형 기본 설정 --> <meta name="viewport" content="width=device-width, initial-scale=1.0">
05
block / inline / inline-block 요소
구분배치크기 지정상하 margin대표 태그
block 항상 새 줄, 가로 100% 차지 ✅ 가능 ✅ 적용 <div>, <p>, <h1~6>, <ul>, <li>
inline 나란히, 콘텐츠 크기만큼만 ❌ 불가 ❌ 무시 <a>, <span>, <strong>, <em>
inline-block 나란히 배치 ✅ 가능 ✅ 적용 <button>, <input>, <select>, <img>
💡 CSS display 속성으로 언제든 바꿀 수 있습니다.
span { display: block; }  /  div { display: inline-block; }
06
목록 태그
<ul>
순서 없는 목록 (bullet point)
<ol>
순서 있는 목록 (1, 2, 3…)
<li>
목록의 각 항목. ul 또는 ol 안에 사용합니다.
<ul> <li>사과</li> <li>바나나</li> </ul> <ol> <li>첫 번째</li> <li>두 번째</li> </ol>
07
테이블 태그 <table>

하나의 데이터가 여러 속성을 가질 때 표 형태로 나열합니다.

<table>
표 전체를 감싸는 태그
<thead> / <tbody>
표의 머리(제목 행)와 본문을 의미적으로 구분. 접근성·스타일링에 유리합니다.
<tr>
행 (table row)
<th>
제목 셀. 기본적으로 굵게 + 가운데 정렬됩니다.
<td>
데이터 셀
<table> <thead> <tr> <th>이름</th><th>나이</th><th>직업</th> </tr> </thead> <tbody> <tr> <td>홍길동</td><td>28</td><td>개발자</td> </tr> </tbody> </table>
08
<img>

이미지를 출력합니다. 닫는 태그가 없는 빈 태그입니다.

src="이미지 url"
출력할 이미지의 경로 또는 URL
alt="문구"
이미지 로드 실패 시 대체 텍스트. 스크린리더가 읽어줘 접근성에 중요합니다.
<img src="photo.jpg" alt="프로필 사진">
💡 <img>는 inline-block 요소라 예외적으로 width/height 지정이 가능합니다.
09
<a> — 링크

다른 페이지로 이동하거나, 같은 페이지 내 특정 위치로 이동하는 링크를 만듭니다.

href="URL"
이동할 페이지 주소. href="#id명"으로 같은 페이지 내 이동도 가능합니다.
target="_blank"
새 탭에서 열기. _self는 현재 탭(기본값).
<!-- 외부 페이지, 새 탭으로 열기 --> <a href="https://example.com" target="_blank">바로가기</a> <!-- 같은 페이지 내 이동 (id로 연결) --> <a href="#section1">섹션1로 이동</a> ... <h2 id="section1">섹션1</h2>
10
<button>

클릭 시 페이지 이동이 아닌 동작(기능)이 실행될 때 사용합니다.

type="button"
일반 버튼. 기본 동작 없음. JS와 연결해 사용합니다.
type="submit"
폼 제출 버튼. <form> 안에서 Enter 키 제출과 유효성 검사를 자동 처리합니다.
<button type="button">클릭</button> <form> <input type="text"> <button type="submit">제출</button> </form>
💡 이동이 목적이면 <a>, 동작이 목적이면 <button>을 사용하세요.
11
폼 관련 태그 <form> / <input> / <textarea> / <select>

사용자로부터 값을 입력받는 태그들입니다.

<form>
입력 요소들을 감싸는 컨테이너. 입력값을 묶어서 전송합니다.
<input type="text">
한 줄 텍스트 입력. value로 기본값, placeholder로 안내 문구를 설정합니다.
<textarea>
여러 줄 텍스트 입력.
<select> + <option>
드롭다운 메뉴. option 태그로 각 항목을 추가합니다.
<form> <input type="text" placeholder="이름 입력"> <textarea placeholder="내용을 입력하세요"></textarea> <select> <option>서울</option> <option>부산</option> </select> <button type="submit">제출</button> </form>
12
<div> / <span>
<div> — block 요소
공간(영역)을 나누는 컨테이너. 레이아웃을 구성할 때 가장 많이 사용합니다.
<span> — inline 요소
텍스트 중 일부 범위만 스타일링할 때 사용합니다. 줄바꿈 없이 텍스트 안에 삽입됩니다.
<!-- div: 영역 분할 --> <div class="card"> <p>카드 안의 내용</p> </div> <!-- span: 텍스트 일부 스타일링 --> <p>가격은 <span style="color:red">1,000원</span> 입니다.</p>
13
<pre>

작성한 여백(들여쓰기)과 줄바꿈을 그대로 브라우저에 출력합니다. 코드 예시를 보여줄 때 주로 사용합니다.

<pre> function hello() { console.log("안녕하세요"); } </pre>
💡 <pre> 안의 내용은 작성한 공백과 줄바꿈이 그대로 출력됩니다. 일반 <p>는 공백·줄바꿈을 무시합니다.
