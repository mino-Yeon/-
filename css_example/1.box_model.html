📦 CSS Box Model

브라우저는 모든 HTML 요소를 사각형 박스로 렌더링합니다.
이 박스가 어떻게 구성되는지 이해하는 것이 레이아웃의 시작입니다.

margin
border
padding
content width × height

Content

텍스트, 이미지 등 실제 내용이 들어가는 공간입니다. width와 height로 크기를 지정합니다.

Padding

콘텐츠와 테두리 사이의 내부 여백입니다. 배경색이 padding 영역까지 채워집니다.

Border

요소를 감싸는 테두리입니다. border: 2px solid #333처럼 두께·스타일·색을 지정합니다.

Margin

다른 요소와의 외부 간격입니다. 배경색이 적용되지 않는 투명한 영역입니다.

💡 기본 크기 계산  box-sizing: content-box 기준
실제 가로 = width + padding × 2 + border × 2
전체 가로 = 실제 가로 + margin × 2

⚙️ box-sizing

width와 height가 어디까지를 포함해서 측정되는지를 결정하는 속성입니다.
이 차이를 모르면 레이아웃이 의도와 다르게 깨지는 경우가 많습니다.

기본값

box-sizing: content-box
width = content 영역만
padding·border가 추가로 더해지기 때문에 실제 렌더링 크기가 지정값보다 커집니다.

✅ 실무 권장

box-sizing: border-box
width = border까지 포함
padding·border가 늘어도 전체 크기는 그대로. 레이아웃 예측이 훨씬 쉬워집니다.
💡 실무 팁 — 거의 모든 현대 CSS 프로젝트는 파일 최상단에 아래 코드를 넣습니다:

*, *::before, *::after { box-sizing: border-box; }

이렇게 하면 width: 300px이 실제로도 딱 300px로 나와서 직관적으로 작업할 수 있습니다.

📏 같은 값, 다른 크기

두 박스 모두 width:200px · padding:20px · border:5px 적용
