⑤ flex-grow / flex-shrink / flex-basis

아이템이 남은 공간을 어떻게 나눌지 결정합니다.

flex-grow — 남은 공간 나누기

컨테이너의 남은 공간을 아이템끼리 비율로 나눠 가집니다. 0이면 늘어나지 않습니다.

flex-shrink — 공간 부족 시 줄어들기

컨테이너가 좁아질 때 아이템이 얼마나 줄어드는지 비율로 설정합니다. flex-basis를 키워서 컨테이너보다 넓게 만들어보세요.

💡 flex-basis를 늘려서 아이템 합계가 컨테이너보다 넓어지면 shrink가 동작합니다. shrink 값이 클수록 더 많이 줄어듭니다.

flex-basis — 기본 크기 설정

아이템의 기본 크기를 설정합니다. width와 비슷하지만 flex 맥락에서 우선 적용됩니다.

.item { flex-basis: 200px; /* 기본 크기 200px, 이후 grow/shrink로 조절 */ flex-basis: auto; /* 콘텐츠 크기 기준 (기본값) */ flex-basis: 0; /* 0에서 시작, grow로만 크기 결정 */ } /* 단축 속성 */ .item { flex: 1; } /* flex: 1 1 0 과 동일 */ .item { flex: 1 0 200px; } /* grow:1 shrink:0 basis:200px */

⑥ 실전 예시

실무에서 자주 쓰이는 Flexbox 레이아웃 패턴입니다.

네비게이션 메뉴

로고를 왼쪽에, 메뉴를 오른쪽에 배치하는 가장 흔한 헤더 구조입니다.

카드 그리드

flex-wrap: wrap과 flex-basis를 활용한 반응형 카드 레이아웃입니다.

.card
카드 제목 1
flex: 1 1 200px
.card
카드 제목 2
창 크기를 줄여보세요
.card
카드 제목 3
반응형으로 줄바꿈
.card-grid { display: flex; flex-wrap: wrap; gap: 12px; } .card { flex: 1 1 200px; }
<div class="card-grid"> <div class="card">카드 1</div> <div class="card">카드 2</div> <div class="card">카드 3</div> </div>

완벽한 중앙 정렬

Flexbox로 수평/수직 동시 중앙 정렬하는 가장 간단한 방법입니다.

.container
.item 완벽한 중앙 ✦
.container { display: flex; justify-content: center; align-items: center; }
<div class="container"> <div class="item"> 중앙 콘텐츠 </div> </div>

사이드바 레이아웃

사이드바는 고정 너비, 콘텐츠 영역은 남은 공간을 차지하는 전형적인 레이아웃입니다.

.layout
.sidebar 사이드바
flex-shrink: 0
.content 콘텐츠 영역
flex: 1
.layout { display: flex; gap: 12px; } .sidebar { width: 240px; flex-shrink: 0; } .content { flex: 1; }
<div class="layout"> <aside class="sidebar"> 사이드바 </aside> <main class="content"> 콘텐츠 </main> </div>
