② 크기 단위

CSS에서 크기를 지정하는 다양한 단위입니다. 기준이 무엇인지가 핵심입니다.

단위 비교 — 기준 font-size: 16px, 부모 너비: 400px, viewport: 800px

절대 단위

px — 픽셀. 화면의 점 1개. 가장 직관적이고 정확합니다.

상대 단위

em — 현재 요소의 font-size 기준
rem — <html>의 font-size 기준
% — 부모 요소 기준
vh / vw — viewport 높이/너비 기준

calc()

서로 다른 단위를 섞어 계산할 수 있습니다. 반응형 레이아웃에서 자주 씁니다.

height: calc(100vh - 60px); /* 전체 높이에서 헤더 높이를 뺀 나머지 */ width: calc(50% - 16px);

⑨ CSS 초기설정

모든 프로젝트 시작 시 작성하는 기본 설정 코드입니다. 브라우저마다 다른 기본 스타일을 통일하고, 자주 쓰는 설정을 미리 잡아둡니다.

초기설정 전체 코드

/* ── 초기설정 Start ───────────────────────── */ :root { /* 프로젝트 전체에서 공통으로 쓸 변수 */ /* --primary: #4cc9f0; */ /* --font-size-base: 16px; */ } *, *::before, *::after { box-sizing: border-box; /* 크기 기준을 border로 */ margin: 0; padding: 0; } body { font-family: 'Segoe UI', sans-serif; line-height: 1.6; color: #333; background-color: #fff; } a { color: inherit; /* 부모 텍스트 색 상속 */ text-decoration: none; /* 기본 밑줄 제거 */ } li { list-style: none; /* 기본 마커 제거 */ } img { max-width: 100%; /* 부모 너비 초과 방지 */ display: block; /* 하단 여백(inline 특성) 제거 */ } button { cursor: pointer; border: none; background: none; font-family: inherit; /* 버튼은 기본적으로 폰트 상속 안 함 */ font-size: inherit; } /* ── 초기설정 End ─────────────────────────── */

각 설정의 이유

선택자 / 속성이유
*, *::before, *::after { box-sizing: border-box }padding/border를 추가해도 전체 크기가 변하지 않아 레이아웃 계산이 직관적. 가상 요소(::before, ::after)에도 동일하게 적용
* { margin: 0; padding: 0 }브라우저마다 h1, p, ul 등에 기본 margin/padding이 달라 통일
body { line-height: 1.6 }기본값(1.2)은 줄 간격이 너무 좁아 가독성이 낮음
a { color: inherit }기본 파란색 링크 색상을 부모 색으로 통일
a { text-decoration: none }기본 밑줄 제거 후 필요한 곳에만 추가하는 방식으로 관리
li { list-style: none }기본 점(•) 마커 제거
img { max-width: 100% }이미지가 부모 컨테이너를 벗어나는 문제 방지
img { display: block }inline 특성으로 생기는 이미지 하단 미세 여백 제거
button { font-family: inherit }button은 기본적으로 폰트를 상속받지 않아 명시적으로 지정
