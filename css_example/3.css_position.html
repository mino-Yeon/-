① static & relative

static은 기본값으로 위치 변경이 불가합니다. relative는 원래 자리를 기준으로 위치를 이동할 수 있습니다.

static

기본 배치 방식. top/left/right/bottom을 설정해도 무시됩니다.

relative — 원래 자리 기준

원래 있던 자리를 기준으로 이동합니다. 원래 자리는 빈 공간으로 유지됩니다.

② absolute

static이 아닌 가장 가까운 부모를 기준으로 위치를 지정합니다. 그런 부모가 없으면 <body>가 기준이 됩니다.

④ sticky

평소엔 일반 흐름대로 있다가, 스크롤이 지정한 위치에 도달하면 그 자리에 고정됩니다. top 값을 반드시 설정해야 동작합니다.

스크롤 데모 — 섹션 헤더가 sticky

아래 영역을 스크롤해보세요. 각 섹션 제목이 상단에 달라붙습니다.

🔵 섹션 1 — position: sticky; top: 0
내용 1-1: Lorem ipsum dolor sit amet consectetur adipisicing elit.
내용 1-2: Porro a iusto pariatur facilis voluptate unde numquam.
내용 1-3: Quae fuga dolorem nulla tenetur quo a ea vero.
🟢 섹션 2 — position: sticky; top: 0
내용 2-1: Numquam voluptatem maiores tenetur ut saepe ex mollitia.
내용 2-2: Debitis perspiciatis voluptatum molestiae quam nesciunt.
내용 2-3: Id sapiente nostrum nulla a quibusdam nisi dicta.
🟡 섹션 3 — position: sticky; top: 0
내용 3-1: Hic dolor odio fuga maxime alias tempore magni.
내용 3-2: Fuga eum voluptatem asperiores vel consequuntur modi.
내용 3-3: Assumenda facilis praesentium a iusto debitis perspiciatis.
🟣 섹션 4 — position: sticky; top: 0
내용 4-1: Ea vero excepturi nesciunt eligendi nihil facilis officia.
내용 4-2: Molestias nobis quam culpa recusandae enim iste porro.

코드

.sticky-header { position: sticky; top: 0; /* 이 값이 없으면 동작 안 함! */ }

sticky vs fixed 차이

값평소스크롤 후부모 영역 벗어나면
fixed항상 고정항상 고정계속 고정
sticky일반 흐름대로지정 위치에 고정같이 사라짐
💡 sticky가 동작하지 않는 흔한 원인
· top 값을 설정하지 않은 경우
· 부모 요소에 overflow: hidden이 설정된 경우
· 부모 요소의 높이가 sticky 요소보다 작은 경우

⑤ z-index

요소가 겹칠 때 어떤 요소가 위에 올라올지 결정합니다. 숫자가 클수록 위에 표시됩니다. position이 static이 아닌 요소에만 적용됩니다.
