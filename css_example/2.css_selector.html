충돌 예시 — 어떤 스타일이 적용될까요?

p color: red 0,0,1
.text color: blue 0,1,0
#title color: green 1,0,0 ✅ 적용됨

점수가 가장 높은 #title(100점)이 이깁니다.
점수가 같으면 나중에 작성된 스타일이 적용됩니다.

⚠️ !important 주의 color: red !important는 점수 계산을 무시하고 무조건 이깁니다.
하지만 남용하면 스타일 관리가 매우 어려워지므로 꼭 필요한 경우에만 사용하세요.

결합자가 포함된 복합 선택자의 점수

결합자( 공백 > + ~ )는 점수에 포함되지 않습니다. 선택자 각각의 점수만 더하면 됩니다.

div p 자손 결합자
div = 1 + p = 1 = 0, 0, 2 (2점)
div > .title 자식 결합자
div = 1 + .title = 10 = 0, 1, 1 (11점)
ul li + li.active 인접 형제 결합자
ul = 1 + li = 1 + li = 1 + .active = 10 = 0, 1, 3 (13점)
#nav ul > li.active:hover 복합 선택자
#nav = 100 + ul = 1 + li = 1 + .active = 10 + :hover = 10 = 1, 2, 2 (122점)
💡 핵심 규칙 — 결합자 자체( 공백 > + ~ )는 점수가 없습니다.
선택자를 쪼갠 뒤 #id(100) · .class / :가상클래스(10) · 태그(1) 를 각각 세어서 더하면 됩니다.
