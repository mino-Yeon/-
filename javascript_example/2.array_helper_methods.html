push · pop

push pop

배열의 맨 뒤에 요소를 추가하거나 제거하는 가장 기본적인 메서드입니다.

push — 맨 뒤에 추가

const fruits = ["apple", "banana"];
fruits.push("cherry");
console.log(fruits);
▶ 실행 결과
["apple", "banana", "cherry"]

pop — 맨 뒤에서 제거

pop()은 제거한 요소를 반환합니다.

const fruits = ["apple", "banana", "cherry"];
const removed = fruits.pop();
console.log(removed);
console.log(fruits);
▶ 실행 결과
"cherry"
["apple", "banana"]
push / pop은 원본 배열을 직접 수정합니다.

splice

splice

특정 인덱스의 요소를 삭제하거나 교체할 때 사용합니다. 원본 배열을 직접 수정합니다.

array.splice(시작_인덱스, 삭제할_개수)

특정 인덱스 요소 1개 삭제

const fruits = ["apple", "banana", "cherry", "mango"];

fruits.splice(2, 1); // 인덱스 2부터 1개 삭제
console.log(fruits);
▶ 실행 결과
["apple", "banana", "mango"]

findIndex와 함께 활용

삭제할 요소의 인덱스를 모를 때는 findIndex로 먼저 찾은 뒤 삭제합니다.

// id가 3인 상품 삭제
const idx = cart.findIndex(item => item.id === 3);
if (idx !== -1) cart.splice(idx, 1);

cart.forEach(item => console.log(item.name));
▶ 실행 결과
MacBook Pro
무선 마우스
USB 허브
키보드
splice는 원본 배열을 직접 수정합니다. 삭제 전 인덱스가 -1인지 반드시 체크하세요.

includes · indexOf

includes indexOf

배열 안에 특정 값이 존재하는지 확인할 때 사용합니다.

includes — 존재 여부 확인 (boolean 반환)

const categories = ["전자기기", "주변기기", "전자기기", "주변기기", "주변기기"];

console.log(categories.includes("전자기기")); // 있으면 true
console.log(categories.includes("가구"));     // 없으면 false
▶ 실행 결과
true
false

indexOf — 처음 발견된 인덱스 반환

찾지 못하면 -1을 반환합니다.

const names = ["MacBook Pro", "무선 마우스", "모니터", "USB 허브", "키보드"];

console.log(names.indexOf("모니터")); // 인덱스 2
console.log(names.indexOf("태블릿")); // 없으면 -1
▶ 실행 결과
2
-1
단순히 있는지 없는지만 확인할 땐 includes를, 위치(인덱스)가 필요할 땐 indexOf를 사용하세요.

forEach

forEach

배열의 각 요소를 순서대로 순회하며 콜백 함수를 실행합니다. 반환값은 없습니다.

cart.forEach(item => {
  console.log(`${item.name} — ${item.price.toLocaleString()}원`);
});
▶ 실행 결과
MacBook Pro — 2,500,000원
무선 마우스 — 35,000원
// ... 총 5개 출력
forEach는 반환값이 없어서 새 배열을 만들 수 없습니다. 단순 출력이나 외부 변수 조작 등 부수 효과(side effect)가 목적일 때 사용합니다.

map

map

각 요소를 가공해서 새 배열을 반환합니다. 원본 배열은 변경되지 않습니다.

// 각 상품에 10% 부가세를 적용한 새 배열
const withTax = cart.map(item => ({
  ...item,
  price: Math.round(item.price * 1.1),
}));

console.log(withTax[0]);
console.log(cart[0]); // 원본은 그대로
▶ 실행 결과
{ id: 1, name: "MacBook Pro", price: 2750000, category: "전자기기" }
{ id: 1, name: "MacBook Pro", price: 2500000, category: "전자기기" }
map은 원본과 길이가 동일한 새 배열을 반환합니다. 각 요소를 변환할 때 사용하세요.

filter

filter

조건을 만족하는 요소만 모아 새 배열을 반환합니다.

// "주변기기" 카테고리 상품만 필터링
const result = cart.filter(item => item.category === "주변기기");
result.forEach(item => console.log(item.name));
▶ 실행 결과
무선 마우스
USB 허브
키보드
// 가격이 100,000원 이하인 상품
const result = cart.filter(item => item.price <= 100000);
console.log(result.map(item => item.name));
▶ 실행 결과
["무선 마우스", "USB 허브"]
filter는 조건에 따라 원본보다 길이가 짧아질 수 있는 새 배열을 반환합니다.

find · findIndex

find findIndex

조건을 만족하는 첫 번째 요소를 찾습니다.

find — 요소 자체를 반환

찾지 못하면 undefined를 반환합니다.

const item = cart.find(item => item.id === 3);
console.log(item);
▶ 실행 결과
{ id: 3, name: "모니터", price: 450000, category: "전자기기" }

findIndex — 인덱스를 반환

찾지 못하면 -1을 반환합니다.

const idx = cart.findIndex(item => item.name === "키보드");
console.log(idx);
console.log(cart[idx].price);
▶ 실행 결과
4
120000
요소 자체가 필요하면 find, 위치가 필요하면 findIndex를 사용하세요. filter와 달리 첫 번째 결과만 반환하고 즉시 종료됩니다.

reduce

reduce

배열의 모든 요소를 순회하며 누적값을 계산해 하나의 결과를 반환합니다.

array.reduce((acc, cur) => { ... }, 초기값)
  • acc — 누적값 (이전 콜백의 반환값)
  • cur — 현재 요소
  • 초기값 — acc의 시작값

장바구니 총 금액 계산

const total = cart.reduce((acc, item) => acc + item.price, 0);
console.log(total.toLocaleString() + "원");
▶ 실행 결과
3,133,000원

카테고리별 총 금액 집계

const byCategory = cart.reduce((acc, item) => {
  const k = item.category;
  acc[k] = (acc[k] || 0) + item.price;
  return acc;
}, {});

console.log(byCategory);
▶ 실행 결과
{ 전자기기: 2950000, 주변기기: 183000 }
reduce는 합계뿐 아니라 객체 집계, 중복 제거 등 다양한 용도로 활용할 수 있습니다. 초기값을 반드시 지정하는 습관을 들이세요.

sort

sort

배열을 정렬합니다. 원본 배열을 직접 수정하므로 주의가 필요합니다.

가격 오름차순 정렬

const byPrice = [...cart].sort((a, b) => a.price - b.price);
console.log(byPrice.map(item => item.name));
▶ 실행 결과
["USB 허브", "무선 마우스", "키보드", "모니터", "MacBook Pro"]

이름 가나다순 정렬

const byName = [...cart].sort((a, b) => a.name.localeCompare(b.name));
console.log(byName.map(item => item.name));
▶ 실행 결과
["MacBook Pro", "USB 허브", "모니터", "무선 마우스", "키보드"]
원본 배열 보존이 필요하다면 [...cart] 또는 cart.slice()로 복사한 뒤 정렬하세요.

메서드 체이닝

chaining

배열 메서드는 새 배열을 반환하기 때문에 연속으로 이어서 호출할 수 있습니다. 이를 메서드 체이닝이라고 합니다.

filter + map

전자기기만 골라서 이름 목록으로 변환합니다.

const result = cart
  .filter(item => item.category === "전자기기")
  .map(item => item.name);

console.log(result);
▶ 실행 결과
["MacBook Pro", "모니터"]

filter + reduce

주변기기 상품의 총 금액을 계산합니다.

const total = cart
  .filter(item => item.category === "주변기기")
  .reduce((acc, item) => acc + item.price, 0);

console.log(total.toLocaleString() + "원");
▶ 실행 결과
183,000원

filter + sort + map

10만원 이상 상품을 가격 오름차순으로 정렬해 이름만 뽑습니다.

const result = cart
  .filter(item => item.price >= 100000)
  .sort((a, b) => a.price - b.price)
  .map(item => `${item.name} (${item.price.toLocaleString()}원)`);

console.log(result);
▶ 실행 결과
["키보드 (120,000원)", "모니터 (450,000원)", "MacBook Pro (2,500,000원)"]
체이닝은 코드를 간결하게 만들어주지만, 단계가 너무 많아지면 오히려 읽기 어려워질 수 있습니다. 3단계 이상이라면 중간 변수로 분리하는 것도 좋습니다.

some · every

some every

조건을 검사해 true 또는 false를 반환합니다.

some — 하나라도 만족하면 true

// 100,000원 이상인 상품이 하나라도 있는가?
const result = cart.some(item => item.price >= 100000);
console.log(result);
▶ 실행 결과
true

every — 모두 만족해야 true

// 모든 상품이 10,000원 이상인가?
const r1 = cart.every(item => item.price >= 10000);
// 모든 상품이 전자기기인가?
const r2 = cart.every(item => item.category === "전자기기");
console.log(r1, r2);
▶ 실행 결과
true false
some은 조건을 만족하는 요소를 찾는 순간, every는 조건을 만족하지 않는 요소를 찾는 순간 즉시 종료합니다.
